Project Blueprint: Custom 3D Printing & Design Shop

1. Project Overview

This document serves as the primary reference for the development of a professional web presence for a locally owned 3D printing business. The site serves two primary functions: a traditional e-commerce storefront and a specialized service portal for custom manufacturing.

Core Identity

Location: Based in Austin, Texas (Local Roots). Proudly serving the greater Austin area (surrounding locations) and the United States.

Primary Hardware: Bambu Lab FDM Printers.

Accepted File Formats: .stl, .3mf, .obj.

2. Site Page Architecture & Hierarchy

Home Page: The "Digital Showroom."

    CTA 1: "Shop Pre-Made Designs" (Redirect to Shop Page).
    CTA 2: "Get a Custom Quote" (Redirect to Custom Work Page).

    Key Content: Hero section, Featured Products, Branding/Local Mission.

Shop Page (WooCommerce): A clean grid-based catalog.

    Categories: Decor, Cake Decor, Board Game Pieces, Collectibles, Arts & Crafts, Tools, Gaming, and other meaningful categories you can think of.

Custom Work Page: The lead generation engine.

Sub-sections: Quote Form, Material Guide(table visual), CAD/Modeling Services.

Portfolio/About Us/Gallery Page: Visual proof of concept.

    Content: Categorized work (Functional vs. Artistic vs. Tabletop), Client Testimonials, Higlights local ownership and the "Craftsman next door" vibe, passion for making.

Help & Support Page: * Content: FAQ, Shipping, Contact/Local Pickup details.

3. Page-Specific Requirements

Custom Work Page (High Priority)

    Workflow Explanation: A "Design-to-Print" step-by-step guide.

    Intake Form: Must support file uploads for .stl, .3mf, and .obj.

    CAD Services: Explicitly mention if 3D modeling/design help is available.

Material Guide (Educational)

    A simplified reference for customers to choose the right plastic:

    PLA: Best for aesthetic decor and internal use.

    PETG: Best for durability and weather resistance.

    Resin: High-detail applications (if applicable/outsourced).

4. Operational Policies (For now build functional links to placeholder text)

Refund Policy

    Custom Work: Strictly non-refundable once the printing process has commenced.

    Standard Items: Standard WooCommerce return logic applies.

Shipping & Handling

    Local Pickup: Address/General area provided for Austin-based customers.

    Packaging: Focus on protection for brittle or thin-walled prints to ensure safe arrival.

5. Technical Specification for AI Agent

When generating code, content, or database schemas for this project, adhere to the following:

    E-commerce Engine: WooCommerce/WordPress.

    Design Aesthetic: Modern, clean, high-contrast (to highlight print textures).

    Tone of Voice: Professional yet local and accessible (The "Expert Neighbor").

    Conversion Goal: Move users from "Curious Visitor" to either a "Shop Buyer" or a "Quote Requester."
